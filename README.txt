LOFI PORTFOLIO
==============

1. Open index.html in your browser.
2. Put your own MP3 inside this folder.
3. Rename it to: music.mp3
4. Open index.html.

Note:
Modern browsers often block unmuted autoplay until the user interacts with the page.
The code tries autoplay first and starts the music on the first click if autoplay is blocked.

Files:
- index.html
- style.css
- script.js
- lofi-bg.jpg
